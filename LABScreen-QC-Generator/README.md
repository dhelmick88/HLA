LABScreen QC Generator

**Overview**
This project automates QC review of LABScreen assays using R. Input files are .csv generated by Xponent software. This specific protocol is only to trend QC.
This specific protocol is only to trend QC. I am hoping to be able to use this for checking new lots/batches/shipments of reagents.
**Features**
Levy-Jennings charts
Separate Class I and Class II analysis
Bead median value trending
Multi-page PDF reports
**Requirements**
R 4.3+
**Required Packages:**
dplyr
openxlsx
ggplot2
gridExtra

**Usage**
Export QC data.
Select input file.
Run the script.

**Disclaimer**
Sample data only. No patient information should be uploaded.
